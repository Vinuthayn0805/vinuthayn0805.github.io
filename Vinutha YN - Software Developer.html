    Meeting minutes, generated
    
        
    Teams meetings produce transcripts nobody rereads. This pulls them automatically and returns the three things people actually want afterwards: what was decided, who owes what, and what is still open.
    
        
      
          
    • Retrieves meetings and transcripts through the Microsoft Graph API, authenticated with Microsoft Entra ID and OAuth 2.0.
      • 
          
    • FastAPI backend that processes the transcript and uses an LLM to draft summaries, decisions, and action items.
      • 
          
    • Stores generated minutes so they can be reviewed and reused rather than regenerated.

    Lead enrichment from Apollo
    
        
    Sales was looking up contacts one at a time. This takes a list of companies and returns verified contact and company details, already checked and ready to import.
    
        
      
          
    • Calls Apollo’s REST APIs to fetch contact and firmographic data for each record.
      • 
          
    • Validates, de-duplicates, and normalises results in Pandas before export.
      • 
          
    • Writes clean output back out for the CRM, so the research step disappears from the sales workflow.

    Ask the data a question
    
        
    An analytics layer for people who don’t write SQL. You type the question, it writes the query, runs it, and explains what the numbers mean.
    
        
      
          
    • Turns a natural-language question into SQL, then runs it and summarises the result.
      • 
          
    • Reads from CSV, Excel, SQL databases, and cloud data sources through DuckDB.
      • 
          
    • Returns the generated query alongside the answer, so the analysis stays checkable.
